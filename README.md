# SpaceOps: hard sci-fi space combat game

Newtonian physics, realistic sensors, energy management, EMCON, EW and missile salvos, built as a hobby simulation. A deterministic simulation core drives a front end (first release: command line plus map plots).

## Layout

- `proto/` Python prototype (milestone M0): models, pytest tests, notebook
- `docs/` links to the design document and the implementation plan
- `PROGRESS.md` resume notes for the multi-session build
